# Screenshots

## Evidence Storage

- One folder per stage: `stage-01/`, `stage-02/`, …, `stage-05/`.
- File names are descriptive: `01-swagger-list.png`, `02-pytest-green.png`, `03-github-actions-green.png`.
- Prefer small, targeted captures (command + output) over full-screen shots.
- Command outputs that are not practical to screenshot may be saved as `.txt` files in
  the same folder.

> Evidence is part of the Definition of Done (see `AGENTS.md` and `docs/stages/README.md`).
> A stage without evidence is not finished.
